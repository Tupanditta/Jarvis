# Persistencia

- **Código:** `core/database.py`, `core/migrations/`.
- **Volver a:** [contexto](../../contexto.md) · [arquitectura](../../arquitectura.md) · esquema en [especificacion-base-datos.md](../../BaseDatos/especificacion-base-datos.md).

## Propósito

Guardar las sesiones, sus actividades y los recordatorios entre ejecuciones (RF-72), con SQLite como única fuente de verdad.

## Comportamiento

- **Motor:** `sqlite3` nativo. Archivo `jarvis.db` en la carpeta de datos (`%LOCALAPPDATA%\Jarvis\data\` en Windows).
- **Conexión:** una sola, creada y usada únicamente en el hilo del núcleo. En cada apertura: `PRAGMA journal_mode = WAL`, `PRAGMA foreign_keys = ON`, `PRAGMA synchronous = NORMAL`, `PRAGMA busy_timeout = 2000`.
- **Transacciones:** cada operación de un repositorio es una transacción (`with conn:`). Las operaciones que cambian varias filas relacionadas (desbordamiento, creación de un recordatorio con sus avisos) van en una sola.
- **Migraciones:** archivos `NNNN_nombre.sql` en `core/migrations/`, aplicados en orden al arrancar según `PRAGMA user_version`. Cada migración se aplica en una transacción y sube la versión. Nunca se edita una migración ya publicada: se añade otra.
- **Borrado lógico (RES-34):** el código no contiene ninguna sentencia `DELETE` sobre `sessions`, `session_activities`, `reminders` ni `reminder_triggers`.
- **Fechas (RES-35):** se guardan como texto ISO-8601 en UTC con desplazamiento explícito (`2026-11-14T17:32:05+00:00`). `database.py` ofrece `to_db(dt)` y `from_db(text)`; `to_db` rechaza fechas sin zona horaria. La conversión a hora local se hace solo al mostrar o decir.
- **Copia de seguridad:** al arrancar, si la versión del esquema va a cambiar, se copia antes `jarvis.db` a `jarvis.db.bak`.
- **Base dañada:** si la base no se puede abrir, se renombra a `jarvis.db.corrupt-<fecha>`, se crea una nueva y se registra el error. El asistente arranca.

## Interfaz

Los módulos no escriben SQL: usan repositorios definidos junto al módulo que los necesita y construidos sobre esta conexión.

```python
class Database:
    def __init__(self, path: Path | Literal[":memory:"]) -> None: ...
    def migrate(self) -> None: ...
    @property
    def conn(self) -> sqlite3.Connection: ...
    def close(self) -> None: ...

class SessionRepository:      # usado por Sesión e Historial
    def create(self, name: str, opened_at: datetime) -> int: ...
    def close(self, session_id: int, closed_at: datetime, reason: str) -> None: ...
    def find_open(self) -> list[SessionRow]: ...
    def get(self, session_id: int) -> SessionRow | None: ...
    def rename(self, session_id: int, name: str, by_user: bool) -> None: ...
    def set_importance(self, session_id: int, important: bool, by_user: bool) -> None: ...
    def count_important(self) -> int: ...
    def oldest_important(self, excluding: int) -> SessionRow | None: ...
    def mark_pending_purge(self, session_id: int, marked: bool, displaced_by: int | None) -> None: ...
    def purge_pending(self, displaced_by: int) -> list[int]: ...
    def soft_delete(self, session_id: int) -> None: ...
    def visible_history(self, limit: int = 10) -> list[SessionRow]: ...
    def name_exists(self, name: str) -> bool: ...

class ActivityRepository:     # usado por run_task e Historial
    def add(self, session_id: int, module: str, description: str, at: datetime,
            parent_id: int | None = None) -> int: ...
    def finish(self, activity_id: int, status: str, description: str | None = None) -> None: ...
    def fail_pending(self, session_id: int, reason: str) -> None: ...
    def of_session(self, session_id: int) -> list[ActivityRow]: ...

class ReminderRepository:     # usado por Recordatorio
    def create(self, content: str, triggers: Sequence[datetime], deadline: datetime | None, at: datetime) -> int: ...
    def listable(self) -> list[ReminderRow]: ...            # activos y vencidos, con sus avisos
    def due_triggers(self, now: datetime) -> list[TriggerRow]: ...
    def future_triggers(self, now: datetime) -> list[TriggerRow]: ...
    def mark_fired(self, trigger_id: int) -> None: ...
    def reschedule_trigger(self, trigger_id: int, new_at: datetime) -> None: ...
    def set_deadline(self, reminder_id: int, deadline: datetime) -> None: ...
    def set_status(self, reminder_id: int, status: str) -> None: ...
```

## Criterios de aceptación

- Las pruebas usan `:memory:` y aplican las migraciones reales.
- Una prueba busca la palabra `DELETE` en el código de `src/` y falla si aparece en una sentencia SQL.
- `to_db` con una fecha sin zona horaria lanza `ValueError`.
- Consultar el historial mientras se registra una actividad no produce errores de bloqueo (RNF-08).

## Prohibiciones

- No se guardan sesiones, actividades ni recordatorios en archivos de texto plano o JSON.
- No se usa `DELETE` físico.
- Ningún hilo distinto del núcleo usa la conexión.
